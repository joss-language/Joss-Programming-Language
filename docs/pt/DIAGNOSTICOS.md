Índice geral: [Documentação Joss](README.md). --- ## O que é um diagnóstico em Joss? Um **diagnóstico** é um relatório técnico estruturado emitido pelas ferramentas Joss (o compilador, o analisador semântico `joss analyze`, o linter ou o tempo de execução defensivo) quando uma violação da sintaxe, tipo ou regras de segurança da linguagem é detectada. Ao contrário das mensagens de erro genéricas de ferramentas mais antigas, cada diagnóstico Joss é projetado seguindo estes princípios: 1. **Identificador único e estável**: Cada regra possui um código imutável (por exemplo `JOSS-TYPE-001`). 2. **Local exato**: Arquivo, linha e coluna precisos onde o conflito se originou. 3. **Explicação pedagógica**: Descreva claramente qual regra foi violada e por quê. 4. **Sugestão acionável**: propõe a correção canônica recomendada. ### Níveis de gravidade - **`error`**: Impede a execução do programa (`joss run` e o compilador para). Representa uma falha estrutural ou de segurança. - **`warning`**: Aviso informativo (como uma variável declarada que nunca foi usada ou uma convenção de nomenclatura desalinhada). `joss analyze` termina com o código de saída `0` se houver apenas avisos, permitindo que a execução continue. --- ## 1. Casos de teste verificados completos Abaixo estão exemplos executáveis ​​que validam formalmente a emissão dos diagnósticos e sua contraparte correta: ### Tipo inexistente ou alias excluído (`JOSS-TYPE-009`)<!-- joss-error: JOSS-TYPE-009 -->
```joss-invalid
integer $edad = 20
```
Caso corrigido com tipo canônico `int`:<!-- joss-run: ["20"] -->
```joss
int $edad = 20
print($edad)
```
--- ### Parâmetro sem tipo explícito (`JOSS-TYPE-011`)<!-- joss-error: JOSS-TYPE-011 -->
```joss-invalid
public func duplicar($valor) { return $valor * 2 }
```
Caso corrigido digitando o parâmetro e o retorno:<!-- joss-run: ["6"] -->
```joss
public func duplicar(int $valor): int { return $valor * 2 }
print(duplicar(3))
```
--- ### Remapear com tipo incompatível (`JOSS-TYPE-001`)<!-- joss-error: JOSS-TYPE-001 -->
```joss-invalid
$edad = 20
$edad = "veinte"
```
Caso corrigido usando dinamismo voluntário (`mixed`):<!-- joss-run: ["veinte"] -->
```joss
mixed $dato = 20
$dato = "veinte"
print($dato)
```
--- ### Retorno ausente nos caminhos de fluxo (`JOSS-TYPE-010`)<!-- joss-error: JOSS-TYPE-010 -->
```joss-invalid
public func signo(int $n): string {
    $n > 0 ? { return "positivo" } : {}
}
```
Caso corrigido garantindo retorno em todas as rotas possíveis:<!-- joss-run: ["no positivo"] -->
```joss
public func signo(int $n): string {
    return $n > 0 ? "positivo" : "no positivo"
}
print(signo(0))
```
